Bluetooth permission blocked?

Brave disables Web Bluetooth. Open this page in Chrome on Android or a supported desktop computer.

In Chrome, tap the site-information icon beside the address, open Permissions, and choose Reset permissions. Then reload this page and tap Choose radio again.

On Android, also open Settings → Apps → Chrome → Permissions and allow Nearby devices. iPhone and iPad browsers do not currently support Web Bluetooth.

Device configuration

Need more control?

Manage stream URLs and, when necessary, the radio’s access code or GPIO wiring.

Advanced settings

Station stream links

Saving these links restarts radio playback so the selected station immediately uses the new configuration.

Physical wiring settings. Each station needs a unique ID, stream URL, and BCM GPIO pin. Incorrect pin numbers can stop the rotary dial from working. These are BCM numbers, not physical header-pin numbers.
Changing this restarts Bluetooth and the fallback portal. The radio will reappear as Radio-XXXXXXXX.

Stations and rotary dial map

IDs are 1–16 letters, numbers, hyphens, or underscores. IDs and pins must both be unique.
Factory settings

Restores the original five stations, links, GPIO pins, and Bluetooth/access code. Saved Wi-Fi networks are preserved.

RadioLink talks directly to the radio over Bluetooth. No Wi-Fi password is sent to this website or stored in your browser.
